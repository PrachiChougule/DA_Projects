# Global AI Job Market and Salary Analysis

## Project Overview

This project explores global AI job-market data using Python libraries to understand job-market trends and salary patterns.

## Objectives

* Explore the AI job market using exploratory data analysis (EDA).
* Analyze salary distributions and variations across available attributes.
* Present patterns through clear data visualizations.

## Technologies Used

* Python
* Pandas
* NumPy
* Seaborn
* Matplotlib

## Project Workflow
1. Imported neccessary Libraries
2. Load the dataset and inspect its structure.
3. Clean and prepare the data where required.
4. Perform exploratory data analysis.
5. Visualize salary distributions and job-market patterns.
6. Interpret findings based on the analysis.

## Files

* `Global_AI_Job_Market_Analysis.ipynb` — Jupyter Notebook containing the analysis.
* `ai_job.csv` — Dataset used for the project.

## How to Run

1. Download or clone this repository.
2. Install the required libraries:
   `pip install pandas numpy seaborn matplotlib`
3. Open the notebook in Jupyter Notebook or VS Code.
4. Update the dataset path if necessary and run the cells.
